# L1 · 数电知识学习验证

## 定位

**用 Verilog 把数电课本上的电路写出来、仿真验证。** 主线是**数字电路本身**，Verilog 只是描述它的工具。

这一级的目标不是"学会 Verilog"，而是"**把数电学扎实，顺便掌握描述电路的 Verilog 基本写法**"。写完的代码，覆盖范围基本就是数电课程的范围。

## 适合谁

- 数电正在学、或刚学完，想把课本上的电路亲手跑一遍
- Verilog 完全没碰过
- 目标是把数电搞扎实，暂时不需要写复杂设计

## 语法范围：刻意做减法

这一级**只用**下面这些，够描述数电课本里的电路就行：

| 会用 | 说明 |
|---|---|
| `module` / 端口 / ANSI 风格声明 | 描述一个电路块 |
| `wire` / `reg` | 连线 vs 寄存器变量 |
| `assign` + 位运算符 | 描述组合逻辑 |
| `always @(*)` + `if` / `case` | 描述真值表 |
| `always @(posedge clk)` + `<=` | 描述时序逻辑 |
| `parameter` 只用于位宽 | 不改电路结构 |

**明确不碰**（这些留给 L2，现在碰只会分散注意力）：

- `generate` / `genvar`
- `function` / `task`
- 文件 I/O（`$readmemh`、`$fopen`）
- 宏 `` `define `` 与条件编译
- 门级原语、UDP
- 复杂的测试台技法（随机激励、覆盖率）

测试台**由我提供**（或带着写最简单的），学习者主要写 RTL。理由是：这一级的重点是电路，不是验证方法学。

## 课程表

### 第一章：组合逻辑（数电的核心）

| 编号 | 数电知识点 | 练习产出 | 测试台自动判定 |
|---|---|---|---|
| L1-01 | 门电路与真值表 | 与/或/非/异或/与非/或非 六种门 | 遍历全部输入组合，比对真值表 |
| L1-02 | 半加器、全加器 | 半加器 + 全加器 | 全真值表 |
| L1-03 | 多位加法器、行波进位 | 4 位行波进位加法器（含进位链） | 全输入组合（含进位溢出边界） |
| L1-04 | 编码器与优先编码器 | 4-2 编码器、4-2 优先编码器 | 全输入组合 + 优先级冲突用例 |
| L1-05 | 译码器 | 3-8 译码器（含使能端） | 全输入组合 + 使能关闭时的输出 |
| L1-06 | 数据选择器与解复用器 | 4 选 1 MUX（用 `case` 实现）、1-4 解复用 | 全输入组合 |
| L1-07 | 数值比较器 | 4 位比较器（大于/等于/小于三输出） | 全输入组合 + 相等边界 |
| L1-08 | 三态门与总线 | 带三态输出的双向总线 | 使能/禁用两种状态 |
| L1-09 | **组合逻辑陷阱**：`if` 缺 `else`、`case` 缺 `default` | 故意写一个带锁存器的模块，再修正 | `latch_inference` 标签 |
| **综合①** | **本章综合题：数值比较显示电路**（译码器 + MUX + 比较器） | 输入两个 2 位二进制数，比较大小，用独热灯显示"大于/等于/小于"，用 MUX 选择要显示的那一路 | **分别验证三个子模块 + 整体** |

> **L1-09 是第一章最重要的一讲。** 漏写分支时**仿真完全正常、行为也对**，但综合器会给你插一个锁存器。这是数电课上讲不到、但实际写代码必然会踩的坑，`tools/_lint.py` 专门抓它。

## 学完的检验标准

能不能**独立**做到下面这几件事：

1. 拿到一个数电课上的电路图或真值表，能翻译成 Verilog 并让它通过测试台
2. 看到一段组合逻辑代码，能立刻判断它会不会推断出锁存器
3. 看到一段时序逻辑代码，能说清楚每个时钟沿之后信号变成什么
4. 能画出自己写的状态机的状态转移图，并和代码对上

## 学完去哪

进 [L2 基础 Verilog 学习](L2-verilog-language.md)。L1 学完的语法只是 Verilog 的一小部分，L2 会把语言全貌铺开。

## 级别内的摸底

L1 摸底重点在**数电本身**，不在 Verilog：

- 与门/或门/异或门的真值表能不能默写
- 组合逻辑和时序逻辑的区别说得出吗
- 触发器、锁存器、寄存器这三个词分别指什么
- 状态机的概念有没有（状态图看得懂吗）
- 有没有写过程序（C 语言即可，Verilog 不管）

按摸底结果跳过前几讲。如果真值表、加法器这些都很熟，可以直接从 L1-06 或第一章末开始。
