# 练习的核心要求：覆盖场景

> **本仓库对练习的要求不是"每讲一道题、题目描述写得很长"，而是"每讲一组题，把这讲的知识点在各种场景下都走一遍"。**

题目描述**清晰即可**——写清要做什么、接口是什么，不必长篇大论。**力气花在题目数量和场景覆盖上。**

理由是：一个知识点只在一种场景下练过，等于没掌握。比如 3-8 译码器会写了，换成低有效输出就卡住、换成双使能就卡住——那些"换个说法"的场景才是真正要覆盖的。

## 题组分层

每一讲的题组按下面的层次组织，**基础题必做，变式题尽量做全，其余按进度**：

| 层次 | 是什么 | 数量 |
|---|---|---|
| **基础题** | 直接对应本讲知识点的最小形态 | 1-2 道 |
| **变式题** | 同一知识点**换场景**——见下表 | 3-6 道 |
| **应用题** | 把它用到一个真实/组合的场景里 | 1-2 道 |
| **调试题** | 给一段**有 bug 的代码**，找出来并修 | 1 道 |
| **综合题** | 跨知识点整合，放在章节末 / 阶段末 | 见下 |

## 变式题的"换场景"维度

同一知识点至少要在这些维度上各走一遍：

| 维度 | 例子（以 3-8 译码器为例） |
|---|---|
| **有效电平** | 输出高有效 → 输出低有效；使能高有效 → 低有效 → 双使能（一高一低，如 74LS138） |
| **位宽扩展** | 3-8 → 4-16（级联两个 3-8） |
| **编码方式** | 二进制编码 → 独热码 → 格雷码（计数器/状态机类） |
| **时序约定** | 同步复位 → 异步复位；上升沿 → 下降沿 |
| **接口约定** | 组合输出 → 带寄存输出（打一拍）；并行 → 串行 |
| **约束条件** | 无约束 → 面积优先 → 时序优先（讲清楚取舍，不要求真综合） |
| **边界情形** | 全 0 / 全 1 / 溢出 / 空满 / 复位瞬间 |
| **实现方式** | `case` / `assign` 表达式 / 移位 / 查表——同一功能多种写法 |

## 综合题

**在合适的阶段引入**，专门练"把多个知识点拼起来"。分两处放：

- **每章末尾 1 道** —— 跨本章的几讲。比如组合逻辑章末：用译码器 + MUX + 比较器做一个"数值比较显示电路"。
- **每级末尾 1-2 道大题** —— 跨整级的综合设计。L1 的收尾是数字钟和密码锁，L2 是 FIFO/UART/APB，L3 是完整交付演练。

综合题**不讲新语法**，只考"学过的东西怎么组合"。题目里要写清**模块划分的接口定义**（可以留一部分给你自己定），并且**测试台会分别验证子模块和整体**。

# 题目格式（清晰即可，不必写长）

每讲的 `README.md` 按这个结构写，**每道题一小节**：

````markdown
# L1-05 题组 · 译码器

## 本讲知识点
（一句话）

## 基础题

### 1. 3-8 译码器 `decoder3_8.v`
**功能**：把 3 位输入译成 8 位独热输出，带高有效使能，使能关闭时输出全 0。

**接口**（照抄，测试台按这个对接）：
```verilog
module decoder3_8 (
    input  wire [2:0] a,     // 地址
    input  wire       en,    // 使能，高有效
    output wire [7:0] y      // 独热输出，高有效
);
```

**真值表**：（组合逻辑给全；有边界要单列一行）

**判定**：全 8 种输入 + 使能关闭 + 锁存器检查

## 变式题

### 2. 低有效输出 `decoder3_8_n.v`
（同上结构，只写和基础题的差异 + 接口）

### 3. 双使能 `decoder3_8_dual.v`
...

### 4. 4-16 译码器 `decoder4_16.v`
...

## 应用题

### 5. 用译码器实现任意三变量逻辑函数
...

## 调试题

### 6. 找出这段代码的问题 `decoder3_8_buggy.v`
（贴出有 bug 的代码，只说要"找出问题并修正"，
不说是什么问题——答案在 solutions/）
````

**格式要求就这些**：功能一句话、接口给全、真值表（必要时）、判定标准。**不要写背景科普、不要写分层提示、不要写自检清单**——那些放在讲解里，不占题目篇幅。

## 命名与写法约定

- 一个文件一个模块，文件名 = 模块名（小写 + 下划线）
- 端口用 ANSI 风格；时钟名 `clk`，同步低电平复位名 `rst_n`（全仓库统一，方便测试台复用）
- 每个文件开头写 `` `timescale 1ns/1ps ``
- **变式题的模块名要能看出差异**：`decoder3_8` / `decoder3_8_n`（低有效）/ `decoder3_8_dual`（双使能）/ `decoder3_8_buggy`（调试题）

## 怎么跑

```bash
# 1. 判定对错
python tools/sim.py exercises/L1-05/decoder3_8.v --tb tests/L1-05/tb_decoder3_8.v --top tb_decoder3_8

# 2. 出波形和结构图（产物在 build/viz/tb_decoder3_8/）
python tools/viz.py exercises/L1-05/decoder3_8.v --tb tests/L1-05/tb_decoder3_8.v --top tb_decoder3_8 --open

# 3. 想在终端直接看波形，加 --ascii
python tools/viz.py exercises/L1-05/decoder3_8.v --tb tests/L1-05/tb_decoder3_8.v --top tb_decoder3_8 --ascii
```

**跑不过的时候先看波形和结构图**，比盯着代码猜快得多：

- **波形**告诉你"实际发生了什么"——是不是少打了一拍、复位没生效、使能没拉起来
- **结构图**告诉你"综合出来是什么"——是不是推断出了锁存器、有没有意外的组合环路

产物都在 `build/` 下（gitignore 的临时目录），每次跑会覆盖。
